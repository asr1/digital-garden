# Software Updates

Software updates are either great or terrible. There is no in-between.

We, collectively, do not know when to call a piece of software done.

### Updates
Software updates should be illegal. 
Since this is an unpopular stance among developers, security researchers, and many users, I'll walk it back:

Software updates are either great, terrible, or invisible. There's a lot of overlap between the great and the invisible!

Bad updates remove features, break workflows, monetize standard processes, or disrupt flow. If you must do a redesign, consider [Boiling the Frog](https://en.wikipedia.org/wiki/Boiling_frog,) like with eBay's famous [yellow story](https://www.cnn.com/2001/TECH/industry/06/07/ebay.lessons.learned.idg/.).
